# Shared Agent Instructions

Read `~/.agents/AGENTS.md` first.
Use `~/.agents/memory-bank/README.md` and the files under `~/.agents/memory-bank/` as the canonical long-lived context.
When a task reaches a milestone or resets context, update `activeContext.md` and `progress.md` instead of restating the whole chat.
Prefer the reusable prompt files in `~/.agents/prompts/` for initialize, resume, and update workflows.
