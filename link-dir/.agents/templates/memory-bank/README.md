# Memory Bank Template

This template is copied into each project as `./memory-bank/`.

Important: the Memory Bank is per project. Do not use this directory as a shared global memory store. Copy these files into the current repository and keep them there.

## Template Files

- `projectbrief.md`
- `productContext.md`
- `activeContext.md`
- `systemPatterns.md`
- `techContext.md`
- `progress.md`

## How To Use

1. Copy this folder into the project root as `memory-bank/`.
2. Read the project’s `AGENTS.md` or tool-specific instruction file.
3. Update the project-local files after significant milestones.
4. Keep `activeContext.md` current and concise.
5. Keep `progress.md` summary-level.
