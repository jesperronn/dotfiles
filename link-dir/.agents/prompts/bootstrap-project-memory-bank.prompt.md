---
description: Bootstrap a per-project Memory Bank from the shared template
---

Create a project-local `memory-bank/` folder in the repository root from the shared template in `~/.agents/templates/memory-bank/`.

Make sure the result is explicit that the Memory Bank belongs to this project only.

Add or update the project’s instruction file so it tells the agent to read the project-local Memory Bank, not a global one.

Keep the files concise and factual.
